# AirPoint MVP

A minimal Next.js dew point calculator.

## Run
npm install
npm run dev

## Test
npm test

## Build
npm run build

## Launch checklist
- Buy/choose a domain only after final brand check.
- Deploy to a production host.
- Add sitemap.xml and robots.txt.
- Add Search Console verification.
- Add privacy/terms/contact pages before monetization.
- Keep calculation tests in CI so failed tests block deployment.
- Treat condensation output as an estimate, not a guarantee.
