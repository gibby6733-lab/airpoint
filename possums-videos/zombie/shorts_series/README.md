# Zombie apocalypse Shorts (TikTok + YouTube Shorts) → #apocalypse-videos

9:16, 60-70 s daily episodes. Likes = supplies, most-liked comment picks what the survivors build/do,
commenters who post NAME + SKILL can join. State in `state.json`; each day in `dayNN/`.

Build: `python3 zombie/build_episode.py zombie/shorts_series/dayNN tts` then `node zombie/short_series.js zombie/shorts_series/dayNN`,
`./discord_copy.sh …/episode.mp4 …/discord.mp4`, `python3 post_discord.py apocalypse zombie/shorts_series/dayNN`.

Captions: only common emojis that show on iPhone (e.g. 🧟 💵 👇 🧱 ⚡ 🗼 🥫 🎒 😬 🔥 ❤️); never text codes like
[Red heart]. Always paste the caption in the chat reply too, ready to copy.
